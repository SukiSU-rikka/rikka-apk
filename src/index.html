声音与朗读声音、读法与情感、高亮、后台听书⌄

声音

连接地址（一般不用改）

用电脑时把 192.168.1.10 改成电脑的 IP。更省心：在六花声库的“电脑”页连接电脑，这里保持“本机”，两边的声音会在同一个列表里。

读法与情感

句号、台词结束后停一下，更像真人讲故事（推荐 0.3～0.5 秒）。

推荐：作者注音、你改过的读音、AI 校对过的读音、明日（あした）这类特殊读法照六花的假名读，其余交给引擎，语调最自然。

朗读高亮

一般不用动（已自动扣除耳机延迟）。高亮总比声音快就往右拖，比声音慢就往左拖。

听书

朗读位置精确记到词：停止后再点“连续朗读”，从停下的那个词接着读；翻到别处则从屏幕上看到的那段开始。

GPT-SoVITS 服务连接

附带的电脑语音服务可自动下载六花模型。启动后手机连接同一 Wi-Fi，填写电脑显示的地址和密钥。电脑需保持运行；系统语音可直接使用。

模型参考音频与合成参数

附带的 VITS 六花模型无需填写参考音频。使用 GPT-SoVITS 时再填写服务器上的参考音频路径和台词。

更换服务器模型后修改此标记，避免播放此前缓存的声音。

✎ 有还没保存的修改（已帮你记住），点“保存语音服务”后才会生效。

AI 服务接口、密钥与剩余额度⌄

AI 讲解与创作

未配置

离线注音不需要账号。自由创作、全文翻译和深入解析，需要你自己的 AI API Key。调用费用由所选服务收取；ChatGPT 会员不包含 API 额度。

AI 用量与缓存

开启后，仅将当前阅读段落发送给你选定的服务；默认只在点“AI 深入解析”时发送。密钥由 Android 系统密钥库加密保存，不写入备份。

✎ 有还没保存的修改（已帮你记住，离开也不会丢），点“保存设置”后才会生效。密钥出于安全不会被记住。

当前 API 余额

保存服务和密钥后可查询。DeepSeek 官方接口支持显示剩余余额。

数据与关于备份恢复、词典来源、版本⌄

备份与恢复

导出书架、阅读位置、解析、生词、旧版学习进度、图片与阅读偏好。换手机时重新导入即可，密钥不会被导出。

恢复时按文档 ID 合并；同 ID 的内容以备份为准。

关于六花

离线读音来自 Kuromoji / IPADIC 形态分析与复合词读音词典的多重验证；内置 6,633 个带中文释义的分级词条和 125 节语法及补充的口语、网络、新闻表达。假名为橙色的人名、专名读音置信度较低，请结合语境核对。

词汇等级仅为学习参考，AI 讲解也需要结合原文核对。扫描版 PDF、受保护的 EPUB、旧版 .doc 不支持直接提取。
