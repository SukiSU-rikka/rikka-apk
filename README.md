# 六花日语 APK 发布

日语阅读学习 App「六花日语」的 Android 安装包发布仓库。

## 下载

👉 [最新版下载（v2.9.0）](https://github.com/SukiSU-rikka/rikka-apk/releases/latest)

或在 [Releases](../../releases) 页面选择历史版本。

## 安装说明

- 包名：cn.rikka.v2
- v2.1.0 及之后版本使用同一签名，**可直接覆盖安装**
- 如果手机上还是 v2.0.0（旧签名），需先卸载再装新版
- 安装包约 31MB，下载后核对大小再安装

## 功能

- 📚 书架：内置 168 部青空文库名作离线直读，另有 16816 部索引离线搜索
- 🔍 找书：青空文库在线搜索
- 📖 阅读器：自动注音（假名标注）、点词看读音、手动纠正读音、进度记忆、字号/深色模式
- 🤖 AI 故事生成：自定义主题、人物、难度（N5~N1、N1+、母语）、表达风格（19 种），支持大纲先行、续写
- 🔍 搜索原作资料：写同人时自动生成原作背景，AI 严格依据原作人设写
- 📝 AI 解析：句子翻译、语法讲解、词汇注释
- 📒 生词本：阅读中收藏生词
- 📝 JLPT 考试：N5–N1 刷题 / 整卷模考（限时可选）/ AI 出题 / 错题本 / 成绩记录 / 听力（设置里打开后显示在底部导航）

## 更新日志

### v2.9.0
- 考试模块升级：新增离线出题器（基于内置 6633 词词汇表与 125 条语法点，按级别无限生成文字・語彙/文法题，迷你/标准/全真三种卷型），不再只依赖固定题库
- 试卷库：生成的卷子可保存、重做、删除；考试可中途「保存并退出」，下次接着答
- 试卷导入/导出：可把试卷导出为 JSON 文件，也可粘贴导入（带严格格式校验）；另内置给 AI 用的出题提示词，可让 AI 按格式出卷再导入
- 错题本、成绩记录沿用原数据，升级不丢失

### v2.8.4
- 搜索补完：补上 鏡・夢・歩・鴎・島・岡・斎・徳・紅・寛 等异体字折叠，泉镜花、梦野久作、江户川乱步、森鸥外、岛崎藤村等名家用简体都能搜到作者

### v2.8.3
- 找书搜索支持作者名：标题、作者一起匹配（此前作者名用中文搜不到会被误以为不支持）
- 搜索支持中文：简体、繁体、日式新旧字体统一归一后再匹配——用「谷崎润一郎」「人间失格」「雪國」都能搜到，不必切换输入法敲日文原字；日文原样搜索不受影响
