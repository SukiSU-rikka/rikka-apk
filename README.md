# 六花日语 APK 发布

日语阅读学习 App「六花日语」的 Android 安装包发布仓库。

## 下载

👉 [最新版下载（v3.1.3）](https://github.com/SukiSU-rikka/rikka-apk/releases/latest)

或在 [Releases](../../releases) 页面选择历史版本。

## 安装说明

- 包名：cn.rikka.v2
- v2.1.0 及之后版本使用同一签名，**可直接覆盖安装**
- 如果手机上还是 v2.0.0（旧签名），需先卸载再装新版
- 安装包约 31MB，下载后核对大小再安装

## 功能

- 📚 书架：内置 168 部青空文库名作离线直读，另有 16816 部索引离线搜索
- 🔍 找书：青空文库在线搜索
- 📖 阅读器：自动注音（假名标注）、点词看读音、手动纠正读音、进度记忆、字号/深色模式
- 🤖 AI 故事生成：自定义主题、人物、难度（N5~N1、N1+、母语）、表达风格（19 种），支持大纲先行、续写
- 🔍 搜索原作资料：写同人时自动生成原作背景，AI 严格依据原作人设写
- 📝 AI 解析：句子翻译、语法讲解、词汇注释
- 📒 生词本：阅读中收藏生词
- 📝 JLPT 考试：N5–N1 刷题 / 整卷模考（限时可选）/ AI 出题 / AI 伪真题卷 / 错题本 / 成绩记录 / 听力（设置里打开后显示在底部导航）

## 更新日志

### v3.1.3

- 修复朗读的“电流声”：VOICEVOX 的 24kHz 声音在 48kHz 播放时的重采样噪声已消除（播放按声音采样率走、预合成做高质量重采样），另加每段 6ms 淡入淡出，拼接处不再有“啪”声。配合声库 v1.1.1 效果更好。

### v3.1.2

- **修复点击朗读可能闪退**：后台听书服务换成防崩溃版（朗读刚开始又马上停止时不再被系统杀掉整个 App）。
- 设置页整体重做：首页是搜索 + 常用设置 + 分类列表，点分类进子页面，改动即时保存。
- 修复声库 HTTP 接口与局域网电脑引擎连不上（网页 CSP 放行 http）。
- 版本号规则调整：3.0.9 之后按 3.1.0、3.1.1 顺序递进，本版顺延为 3.1.2。

### v3.0.11

- **后台听书**：锁屏或切到别的 App 继续朗读，通知栏与耳机按键可控制（上一段/暂停/下一段），来电或别的 App 放音乐时自动暂停。壳子新增朗读前台服务与媒体会话。
- **广播剧模式**：AI 识别台词的说话人与情绪，自动分配 VOICEVOX 角色与情绪风格（按书缓存）。
- 朗读高亮扣除音频输出延迟、可手动校准，短词与标点不再漏标；高亮样式与颜色可选；句间自然停顿；英文单词转片假名朗读，装饰符号不念。
- （含 3.3.0 网页改动：朗读位置精确记忆到词、跟读模式、定时停止、朗读时屏幕常亮。）

### v3.0.10

- 修复朗读控制条撑满整屏：两处样式定位冲突，现为底部一条紧凑胶囊控制条。

### v3.0.9

- **朗读改用 Web Audio 播放**：不再用系统播放器元素，修复“必须手势才能播放”“引擎没有返回可播放的音频”；WAV 由页面自己解析，不依赖 WebView 解码器。
- **无缝衔接**：后面的句子提前合成、首尾相接排队播放，句间无空档；开书时后台先合成第一句，点连续朗读立刻出声。
- **逐词高亮**：读到哪个词哪个词亮起、读过的变色（需六花声库 v1.0.5 的时间轴数据，其它引擎按音拍估算）。
- **点词暂停**：朗读中点任意词立即暂停，关掉释义弹窗后从点的词接着读。
