# 六花日语 APK 发布

日语阅读学习 App「六花日语」的 Android 安装包发布仓库。

## 下载

👉 [最新版下载（v3.0.9）](https://github.com/SukiSU-rikka/rikka-apk/releases/latest)

或在 [Releases](../../releases) 页面选择历史版本。

## 安装说明

- 包名：cn.rikka.v2
- v2.1.0 及之后版本使用同一签名，**可直接覆盖安装**
- 如果手机上还是 v2.0.0（旧签名），需先卸载再装新版
- 安装包约 31MB，下载后核对大小再安装

## 功能

- 📚 书架：内置 168 部青空文库名作离线直读，另有 16816 部索引离线搜索
- 🔍 找书：青空文库在线搜索
- 📖 阅读器：自动注音（假名标注）、点词看读音、手动纠正读音、进度记忆、字号/深色模式
- 🤖 AI 故事生成：自定义主题、人物、难度（N5~N1、N1+、母语）、表达风格（19 种），支持大纲先行、续写
- 🔍 搜索原作资料：写同人时自动生成原作背景，AI 严格依据原作人设写
- 📝 AI 解析：句子翻译、语法讲解、词汇注释
- 📒 生词本：阅读中收藏生词
- 📝 JLPT 考试：N5–N1 刷题 / 整卷模考（限时可选）/ AI 出题 / AI 伪真题卷 / 错题本 / 成绩记录 / 听力（设置里打开后显示在底部导航）

## 更新日志

### v3.0.9

- **朗读改用 Web Audio 播放**：不再用系统播放器元素，修复“必须手势才能播放”“引擎没有返回可播放的音频”；WAV 由页面自己解析，不依赖 WebView 解码器。
- **无缝衔接**：后面的句子提前合成、首尾相接排队播放，句间无空档；开书时后台先合成第一句，点连续朗读立刻出声。
- **逐词高亮**：读到哪个词哪个词亮起、读过的变色（需六花声库 v1.0.5 的时间轴数据，其它引擎按音拍估算）。
- **点词暂停**：朗读中点任意词立即暂停，关掉释义弹窗后从点的词接着读。

### v3.0.8

- **朗读改走「直连通道」**：六花日语通过系统接口直接调用六花声库，不再经过任何网络端口——新系统（Android 17 / ColorOS）不允许普通 App 监听本机端口，旧方式会直接被系统拒绝。需搭配**六花声库 v1.0.2**（单独仓库 rikka-voice）。
- 本机接口改为多端口依次探测兜底（50021 / 50031 / 52021 / 38021 / 18021）；访问电脑上的语音服务（AivisSpeech 等）不变。
- 壳子配套：新增直连桥与对六花声库的包可见性声明。

### v3.0.7
- 朗读接入「六花声库」：设置 → 声音与朗读 新增朗读来源「六花声库 / AivisSpeech / VOICEVOX」（VOICEVOX 兼容接口），可从声音列表选音色、抑扬（语调）滑块；原有「系统日语语音」「GPT-SoVITS」保持不变
- 旁白 / 台词分声音：「」『』里的台词可以用另一个声音读，和旁白区分开
- 读音对齐：朗读按六花的注音读音走——作者标注的读音（如 本気《マジ》）会按 マジ 读，不再让语音引擎自己猜
- 预合成下一句：连续朗读时提前合成下一句，段落之间衔接不卡
- 配套调整：壳子放行本机接口（127.0.0.1），在六花里点一下就能拉起「六花声库」App 开启本机接口（需另行安装六花声库）

### v3.0.6
- 新图标「六花」：雪花与花瓣合一的浅色新图标（设置里的图标预设同步换新，旧图标保留为 v1）
- AI 用量与缓存：设置 → AI 服务底部新增「AI 用量与缓存」面板，各功能的请求数、缓存省下的次数一目了然；单词解析结果跨书缓存（换一本书遇到同一个词直接命中、不用再花钱问 AI），整段解析也走缓存；预解析会跳过助词和常见词、同一页同一个词只问一次，更省 token
- 手动纠正读音升级：点词弹窗里「读音不对？我来改」——能把被分词器切碎的词补全（如 美 → 美琴）再填读音，可选「只在这本书里改」或「所有书都这样读」，正文立刻更新
- 单词解析专用模型（可选）：可给点词解析 / 预解析单独指定一个更便宜的小模型，不用跟主模型挤
- 在线找书新增「找日文原作」：输入中文译名（如「无职转生」），列出日文原题并找到なろう上的作品，可直接点开导入
- 注音更稳：AI 给出的读音若不在词典候选里就不采用，防止 AI 把本来正确的注音改错；「心中」按语境区分 しんちゅう / しんじゅう
- 底层：解析缓存迁入独立的数据库仓库（IndexedDB 升级到 v2），书架、生词等原有数据不受影响

### v3.0.5
- 读音统一：新增读音同步层——整段解析、点词解析给出的读音会回写到正文注音（旧书已保存的解析也生效，不用重解析），正文、解析列表、点词弹窗三处读音从此一致；解析的 span 信息还能把被分词器切碎的词合并回来
- 注音内置校订：陽キャ→ようきゃ、陰キャ→いんきゃ、罰ゲーム→ばつげーむ、嘘告→うそこく（走 curated 优先，AI 不覆盖）
- 解析折叠分工：新增「只收起词汇与语法」开关（翻译保留），与整段折叠互不影响、状态都会记住；收起时点标签可临时展开单段
- 主题特效重做：动态层改为单块 canvas 绘制（限 30 帧、切后台自动暂停），删掉旧 CSS 粒子动画——之前的闪屏就是它；新增花吹雪 / 紅葉 / 初雪等主题与苺ミルク、綿あめ、ゆめかわ、星降る夜；「飘落特效」可独立选（樱花/红叶银杏/细雪）并调数量，任意主题和自定义背景都能叠加；右上角日/夜切换会记住各自上次用的主题
- 设置更顺手：设置页记住展开的分组与滚动位置；AI/语音服务改动自动存草稿（离开再回来还在，有「未保存修改」提示）；AI 开关类选项即改即存
