# 六花日语 APK 发布

日语阅读学习 App「六花日语」的 Android 安装包发布仓库。

## 下载

👉 [最新版下载（v3.0.5）](https://github.com/SukiSU-rikka/rikka-apk/releases/latest)

或在 [Releases](../../releases) 页面选择历史版本。

## 安装说明

- 包名：cn.rikka.v2
- v2.1.0 及之后版本使用同一签名，**可直接覆盖安装**
- 如果手机上还是 v2.0.0（旧签名），需先卸载再装新版
- 安装包约 31MB，下载后核对大小再安装

## 功能

- 📚 书架：内置 168 部青空文库名作离线直读，另有 16816 部索引离线搜索
- 🔍 找书：青空文库在线搜索
- 📖 阅读器：自动注音（假名标注）、点词看读音、手动纠正读音、进度记忆、字号/深色模式
- 🤖 AI 故事生成：自定义主题、人物、难度（N5~N1、N1+、母语）、表达风格（19 种），支持大纲先行、续写
- 🔍 搜索原作资料：写同人时自动生成原作背景，AI 严格依据原作人设写
- 📝 AI 解析：句子翻译、语法讲解、词汇注释
- 📒 生词本：阅读中收藏生词
- 📝 JLPT 考试：N5–N1 刷题 / 整卷模考（限时可选）/ AI 出题 / AI 伪真题卷 / 错题本 / 成绩记录 / 听力（设置里打开后显示在底部导航）

## 更新日志

### v3.0.5
- 读音统一：新增读音同步层——整段解析、点词解析给出的读音会回写到正文注音（旧书已保存的解析也生效，不用重解析），正文、解析列表、点词弹窗三处读音从此一致；解析的 span 信息还能把被分词器切碎的词合并回来
- 注音内置校订：陽キャ→ようきゃ、陰キャ→いんきゃ、罰ゲーム→ばつげーむ、嘘告→うそこく（走 curated 优先，AI 不覆盖）
- 解析折叠分工：新增「只收起词汇与语法」开关（翻译保留），与整段折叠互不影响、状态都会记住；收起时点标签可临时展开单段
- 主题特效重做：动态层改为单块 canvas 绘制（限 30 帧、切后台自动暂停），删掉旧 CSS 粒子动画——之前的闪屏就是它；新增花吹雪 / 紅葉 / 初雪等主题与苺ミルク、綿あめ、ゆめかわ、星降る夜；「飘落特效」可独立选（樱花/红叶银杏/细雪）并调数量，任意主题和自定义背景都能叠加；右上角日/夜切换会记住各自上次用的主题
- 设置更顺手：设置页记住展开的分组与滚动位置；AI/语音服务改动自动存草稿（离开再回来还在，有「未保存修改」提示）；AI 开关类选项即改即存

### v3.0.4
- 新增书源「カクヨム」：排行 / 搜索（字数、状态筛选，可粘贴作品链接直达）/ 目录 / 正文导入，作者注音保留；走原生网络通道（本版起放行 kakuyomu.jp 并用桌面版 UA 解析，与 Novelty 的实现对齐）
- 在线找书改版：青空文库加「分类推荐」（8 组作者）；なろう加状态 / 篇幅 / 分类筛选和热门标签；内置书库按新版设计取消（离线内容走青空精选与导入）
- 主题扩到 15 套：新增 9 套动态主题（液态玻璃、猫町、夜桜等，带粒子/飘落效果），设置里可关「主题动态效果」
- 点词秒开：打开文章后整页单词预解析（顶部显示进度），点词立刻出释义；整段解析可一键折叠/展开并记住状态

### v3.0.3
- 点词改为即时 AI 解析：点正文里任何一个词，除了秒出离线词典释义，还会把「这个词 + 所在句子」发给已配置的 AI，补上它在本句里的意思、词性、构成拆解（如 ベテラン＋ニート）、活用变化、外来语原词和例句；词库里没有的词不再只显示「暂未收录」
- 解析结果本地缓存（同一句同一个词只请求一次，之后断网也能看）；没填 API Key 时显示「离线词库里没有这个词」和去设置按钮，不报错
- 设置页 AI 区新增开关「点词即时 AI 解析」，默认开
- 本版只动网页层，原生部分（含なろう网络通道）与 v3.0.2 完全一致

### v3.0.2
- なろう网络通道补齐（原生层）：查明なろう一直加载失败的真正原因——安装包壳会把 WebView 发出的一切外部请求直接拦成 403，网页里的直连、JSONP、公共代理全都走不通；本版给壳的 Bridge 补上专用网络方法（只允许 syosetu 三个域名，重定向逐跳校验），なろう的书单、目录、正文改走这条原生通道，不再依赖代理
- narou.js 相应调整为原生通道优先；旧版没有该通道时会明确提示需更新，不再无限加载失败

### v3.0.1
- なろう书库修复：书单 / 搜索 / 排行改走官方 API，不再被跨域拦截；目录、正文按 2024 年改版后的页面结构重新解析，支持目录翻页（每页 100 话）、短篇与章节标题；导入时弹窗选章节范围；搜索框可直接粘贴作品链接或 N 码；修复「完结 / 连载中」标签判断写反、分类不显示
- 原文注音优先：青空文库与なろう原文自带的作者注音不再被丢弃，导入时单独保存、阅读时按位置覆盖自动注音（正文不变，朗读与 AI 分析不受影响）；作者只标一次的人名，全书沿用同一读音。书架上已有的书需重新导入才生效；内置书库的书打包时已去掉注音，无法恢复
- 词典优先：分词器不认识、被切成单字的汉字复合词，词典有整词收录时以词典为准（聖剣、王都、魔導具、獣人、剣聖 等）
- 小说常见误读修正：兎に角／兎も角、辿り着いた、坊ちゃん／婆や／お姉様、〜を後にする、如何して、日本（にほん）等
